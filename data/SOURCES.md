# Image sources

The 55 photos in `data/images/` were downloaded from Unsplash (https://unsplash.com) and are used under the
Unsplash License (https://unsplash.com/license), which allows free use, including in projects like this one,
without asking permission. Individual photographer credits were not recorded when the files were downloaded.

Filenames start with the animal class (fox, wolf, dog, bear, deer, blurry, lookalike, other) and the labels in
`data/image_truth.json` were written by hand from those prefixes and by looking at the unusual images.
The photos are only used to run and evaluate this capstone; this repository does not claim ownership of them.
